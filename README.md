# Aevum Protocol — Public Repository

This repository contains the publicly available modules of the Aevum Protocol. We continuously release new components as they reach a stable state.

## What's Already Open
- Core data structures (`aevum-core`)
- Consensus interfaces (`aevum-consensus`)
- Database engine (`aevum-db`)

## What's Coming Next
- Node implementation (`aevum-node`)
- API gateway (`aevum-api`)
- L2 settlement (`aevum-l2`)

We believe in gradual transparency. Every week we release new code — you can follow our progress here.
